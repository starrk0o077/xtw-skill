# WeChat Science Writer (公众号科研资讯写作)

高度模仿生物医学顶刊解读类公众号（面向临床科研人群的科研资讯平台）的真实写作风格，将顶刊论文转化为高质量、高信息密度的公众号研究解读文章。

本技能基于对原号 6 篇真实文章的深度学习归纳，务必严格遵循，不要依赖任何先入为主的"自媒体写作套路"。

## 写作人格总览

- **定位**：临床科研人员的前沿文献深度解读工具——既是科研热点解读，也是方法/思路拆解。
- **读者**：临床医生、临床科研人员、医学生，需追踪顶刊动态、理解研究机制、寻找课题灵感。
- **核心追求**：极强信息密度 + 严谨机制拆解 + 可落地的思路借鉴。拒绝流水账、拒绝大而空。

## 核心方法论（用户已确认认可，最高优先级）

**这是"资讯类"与"学术类"的正解，必须严格遵循：用资讯的壳装学术的内容。**

- **资讯感不是靠"写得少"**：来自①标题抓人、②开头一屏内让读者知道"今天讲什么、为什么值得看"、③分段节奏快、每节讲完一层就走、④不铺废话。
- **内容厚度与学术论文看齐**：发表机构、方法路线、样本量、关键数据、机制、图号一样不少。
- **唯一判断标准**：读者滑手机能被开头钩住，停下来后每段都有实货，读完不觉得灌水。
- **成稿节奏（已确认的写法）**：
  1. 开头一屏 = 领域痛点/悬念 + 点明"什么期刊+什么课题+核心亮点"（资讯化切入）；
  2. 紧接着发表信息段（时间/机构/期刊/论文英文名/一段概述）；
  3. 正文全部用具体数据与机制推进（硬核）；
  4. 收尾 = 研究总结 + 热点思路推荐 + 临床发文指南 + 参考文献。
- **禁止**：把"资讯类"当"少写"的借口；把"学术类"当"堆料/灌水"的理由。

## 真实结构模板（严格按此布局，两种变体）

原号存在两种结构，按文章类型选择：

### 变体 A —— 单篇论文机制解读（最常用）

```
标题（期刊背书 + 核心发现 + 惊叹/问句）
  ↓
导读（加粗，200-300字浓缩摘要：做了什么+方法+关键数据+意义）
  ↓
发表信息段（时间 + 团队/机构 + 期刊 + 论文英文名 + 一段研究概述）
  ↓
（可选广告位：课题定制服务）
  ↓
一、研究背景
  ↓
二、研究方法 / 研究思路
  ↓
三、主要研究结果
   （1、加粗小标题 长段落 图号 图1/图2...）
   （2、... 每个核心发现有独立小节）
  ↓
四、研究总结（或：小编总结 / 总结与讨论）
  ↓
（可选广告位）
  ↓
参考文献（学术引用格式）
  ↓
热点思路推荐（标题 + 链接列表）
  ↓
临床医生发文指南（标题 + 链接列表）
```

### 变体 B —— 方法综述 / 顶刊速递（多篇关联、美术综述型）

```
口语化开头（"大家好呀！"+ 热点铺垫 或 "导读："）
  ↓
发表信息段（相关顶刊列表 + 共性介绍）
  ↓
一、研究背景
  ↓
二、研究思路与实验设计流程
  ↓
三、研究主要结果（编号小节 + 图）
  ↓
四、研究总结与讨论
  ↓
参考文献 → 热点思路推荐 → 临床医生发文指南 → 推广脚
```

**关键结构要点**（所有变体通用）：
1. **发表信息段必须存在**：交代时间、期刊、论文名、一段研究概述；**团队/机构可详可略**——有的写全团队（如"中山大学附属第一医院陈淑玲、尹长军、匡铭等团队"），有的只写单位，有的只写期刊不写作者（如"8月7日《Frontiers in Immunology》的一项研究"）。依已知信息丰满度灵活。
2. **研究结果必用数字小节**：`1、小标题`、`2、小标题`...每个发现一段长文，末尾带 `图N.说明文字`；图号可含子图（如"图1D–H"）。
3. **章节编号规范（实测有三套，按文风选择）**：
   - 汉字序：大章用"一、二、三、四"；章内小节用阿拉伯数字"1、2、3、"（顿号）。
   - 学术标签式（无序号）：直接用"研究背景 / 研究方法 / 主要结果 / 小编小结"作章标题。
   - 纯数字章：一级标题也用"1 2 3 4"（空格分隔、可无顿号），如干湿结合解读。
4. **总结章标题可变化**：研究总结 / 小编总结 / 总结与讨论 / 小编小结 / 方法学借鉴（方法向文章以"方法学借鉴"代总结），不强制统一。
5. **参考文献非必带**：综述/图谱/多组学类常列（带 doi），纯单篇机制解读可能不列。有则用学术格式。
6. **IF 标注灵活**：多数文章不写影响因子，个别会写（如"IF：52.5"）；不强制，若要写须核实准确。

## 标题规则

1. **期刊背书开篇**：用顶刊名建立权威感。
   - 示例：`Cancer Cell ｜ PD-1阻断不只是激活T细胞，中山一院团队揭示TLS驱动的B细胞抗肿瘤新机制`
   - 示例：`Nature ｜ HCMI发布全球最大新一代患者来源肿瘤模型图谱！`
   - 示例：`Nature Medicine ｜ 29个器官和40种组织刻画"组织时钟"，测出器官真实衰老状态`
   - 示例：`频繁亮相顶刊，ADC的下一个黄金赛道？Nature Medicine教你做下一代ADC`
2. **结构**：「期刊名 ｜ 核心发现 + 【团队/价值点/悬念】」，或用问句/惊疑句制造钩子。
3. **关键信息前置**：期刊名 + 核心发现在标题前半出现。
4. **适度标点**：问句、惊叹号可用但克制，不堆叠。
5. **必含硬信息**：研究主体指标（器官数量、样本量、患者数、新机制名等）尽量进标题。

## 开头手法（严格两种可选）

1. **学术导读式**（变体A为主）：开头先写 `导读：` 加粗段，浓缩全文核心——做什么、怎么做、关键数据、研究意义。
2. **口语化热点式**（变体B/"大家好呀"）：以行业热点/顶刊动态铺垫，引出今日论文。
- **无论哪种开头，信息密度都必须高**：一段话里给出团队、期刊、方法、样本量、核心机制。

## 叙事结构（固定五段 + 结果小节）

1. **一、研究背景**：说明该研究针对的临床/科研问题、现有方法局限、为什么重要。加粗关键背景句。
2. **二、研究方法 / 研究思路**：按步骤拆解"作者怎么做"，讲技术路线（如单细胞+空间+功能验证闭环），首次术语给中文全称 + 缩写。
3. **三、主要研究结果**：数字小节，每节一个核心发现，长段落展开，带具体数据与图号。
4. **四、研究总结**：复盘核心贡献 + 临床/科研意义 + 局限（可提）。
5. **参考文献**：标准学术格式。

### 结果章节的"分析流程"写法（已验证，强烈倾向采用）

单细胞/测序类研究的结果章节，**不要只罗列 3-4 条结论**，而是把"这一结果到底怎么分析出来的"写成可复现的五步流程，加在每个结果前，让读者能照着做：

- **开篇先给"解题钥匙"**：用 Step 1-5 列完整分析流水线——① 数据整合与质量控制（解卷积矩阵、Harmony 批次矫正、低质量细胞过滤标准）→ ② 细胞亚群鉴定与功能注释（聚类算法、经典标志基因）→ ③ 分组差异比较（组内占比与表达、跨样本汇总消除偶然性）→ ④ 通路富集与细胞互作（KEGG/GO、配体-受体分析）→ ⑤ 功能验证（体内/体外因果实验）。
- 每一步用一个小工具条（如`【Step 1】数据整合与质量控制`）带出，讲清"这一步在做什么、关键参数/标准是什么"。
- **每个"结果"小节 = 一个分析动作 + 一张图**：先说分析做了什么（如"把14个癌种里 SPP1⁺ 巨噬占比画出来，多数落在对角线下"），再给结果图，再用一句话点破结论。
- 用"相关性 → 富集/互作 → 因果验证"递进：先展示差异（相关性），再解释机制（富集/互作网络），最后用功能实验封死因果（如"敲掉一个基因，女鼠免疫治疗被救回来"）。

### 内嵌 SVG 数据图规范（公众号可原样粘贴，已验证）

结果配图**推荐用内嵌 `<svg>` 绘制**（不是外链图片），优点：清晰、可缩放、粘贴不丢、配色可控。约定：

- 配色与封面一致**柔和低饱和避亮蓝**：主色 `#0a6b5c`（深绿），辅色 `#7fb59a`（浅绿）与 `#d49a6a`（暖沙），背景 `#faf8f3`，图内文字 `#1f2b26` / 说明 `#8a8577`。禁止大面积高饱和蓝。
- 典型图表类型对应场景：
  - **占比分组对比**：并列柱状图（男/女两组、多个癌种），柱体 `#7fb59a` vs `#d49a6a`。
  - **通路富集**：横向条形图（−log10(P)），主通路线 `#0a6b5c`、次要 `#7fb59a`。
  - **细胞互作**：两个圆节点 + 带宽度/透明度差异的连接线，标注关键配受体（如 SPARC、LGALS9、CD274/PD-L1）。
  - **UMAP/降维**：散点点云分组示意。
- 每张图固定结构：`<div class="figbox">` 内 `<svg width="520" height="...">` + 下方 `<div class="figcap"><b>图 N</b>｜...说明</div>`；SVG 内顶部有一个居中图标题。
- 说明文字必须含数据结论（如"SPP1⁺ 巨噬在多数癌种女性占比更高，经跨癌种批次校正"），不写空泛无信息量的话。
- 注意：**若结果图依赖真实数据数值，SVG 中的坐标/柱高应为示意且忠于论文趋势**，不可伪造夸大；如数值为示意占位需在说明中标注"示意"。

## 语言特征（原号实测，务必对齐）

- **极高信息密度**：每段都有实打实的数据、机制、方法细节。绝不写"该研究意义重大"这类空话。
- **硬数据驱动**：样本量、患者数、百分比、生存期、基于具体数字（如"38.9%的抗体可识别HBcAg""95.7%的BCR仅存在于肿瘤内""97.8%遗传一致性"）。
- **学术语体 + 中文全称**：专业缩写首次出现给全称，如"抗体药物偶联物（antibody–drug conjugate，ADC）""三级淋巴结构"。
- **长段落**：一个机制点用完整长段讲透，可引出现象→机制→证据的递进。
- **图配合**：结果小节约3-6个，每节配图号`图1.说明`。
- **加粗强调**：关键背景、核心机制、数据结论用 `**` 加粗。
- **客观克制**：不夸张堆叠形容词，用事实和数据说话。（注意：允许少量"大家好呀"式初始句，但不把它当必须）

## 固定收尾板块

1. **参考文献**：标准学术格式：
   作者, et al. 文章标题. 期刊缩写. 年份. doi:编号
2. **热点思路推荐**：标题 + 相关延伸方向。注意原号此处实际是**链接列表**（指向引导文章），若无可链接内容则保留标题 + 简要方向。
3. **临床医生发文指南**：标题 + 相关指引/链接。
4. **推广脚**（可选）：平台定位文案（如"专注临床科研..."+"扫码关注"），但**使用本公众号自己的定位语，避免未经授权的"生信人"字样**。

## 封面/配图风格偏好

- 配色以**柔和的深色或低饱和色**为主（如深藏青、雾灰、暖白），**避免大面积亮蓝色/高饱和度蓝色**，减少刺眼感。
- 风格：科学可视化、专业、干净，避免花哨渐变和过亮荧光色。
- 场景需配图时据此风格生成。

## 内容选题偏好

- **以肿瘤学为绝对核心**：ADC 药物、肿瘤类器官、肿瘤微环境、免疫治疗（PD-1/TLS/B细胞）、耐药机制。
- **多组学与生信**：单细胞测序、空间转录组、CRISPR 筛选、全基因组/转录组分析。
- **计算病理学/AI**：深度学习、虚拟肿瘤微环境、H&E 图像分析、空间蛋白组。
- **衰老与神经科学**：组织时钟/器官衰老、空间图谱等。
- **优先解读近 1-2 年发表的 CNS 级研究**，倾向转化医学类（Nature Medicine、Cancer Cell）。

## 期刊偏好

- 解读对象以 **CNS 级顶刊**为主：Nature、Cell、Cancer Cell、Nature Medicine。
- 兼顾 AI/计算交叉顶刊：Nature Machine Intelligence、Cell Reports Methods 等。

## 公众号发布形式偏好（强约束）

- **采用「1+2」合集推送形式**：每次 `draft/add` 调用，**articles 数组必须传 3 条**（不是 2 条、不是 1 条）。结构：
  - 第 1 条 = 主条（最重磅的研究）
  - 第 2 条 = 子条（次重磅）
  - 第 3 条 = 子条（再次重磅）
- 3 条**全部为真正的研究内容**，**严禁在主条位置放置"汇总介绍/导览"页**。
- 主条按阅读价值排序；同合集 3 篇风格必须统一（标题句式、字数密度、收尾板块）。

## 输出约定

- 用中文写作，**正文必须用 100% 行内 style 的 HTML**（公众号后台粘贴会剥离 `<style>` 块和 CSS 类），不依赖外部 CSS。
- 交付时包含：标题（1 个主标题 + 1-2 个备选）、正文 HTML、参考文献来源。
- 保留准确性：不虚构数字、结论必须忠于论文事实；不确定的地方用待核实占位。
- **内容必须详实丰"富"**：一篇正文目标 1500-2500 字，信息密度对齐原号，不因"保持简洁"而损失机制细节。

### 正文 HTML 排版规范（对齐已确认的 VirTues 样稿）

- 外层容器：`font-size:16px`、`color:#3a3d44`、`line-height:1.9`、`letter-spacing:0.3px`，段与段之间 `margin:0 0 26px 0`（大空行）。
- 中文专有名词给全称 + 缩写（如 `空间蛋白组学（CODEX、IMC、MIBI、Orion 等）`，关键术语用 `<b>`）。
- 大章标题：`<b style="color:#0a6b5c;">一、研究背景</b>`，其下紧跟正文段落。
- 结果小节：`<b>1、小标题</b>` 独立一行，其后接长段落；机制要点用 `<b>` 标出。
- 正文与公众号后台粘贴兼容（仅 p + b 加行内 style，不引入复杂标签）。

## 发布后管理约定（用户偏好，务必遵守）

- **只创建新的草稿/合集，不做删除操作**——旧草稿由用户自行清理，助手不得代删。
- 建立草稿时，若 `articles` 为 3 条即构成 1+2 合集；如需重跑/替换，一律生成新的 draft 而不是覆盖旧的。
- 提交流程涉及微信 API（`token → material/add_material → draft/add`），若遇 IP 未在白名单错误，向用户报告当前出口 IP 并等待放行，不擅自绕过。

# 附加写作模式（仅用户显式指定时启用）

以下模式由其他写作技能整合而来。**默认不启用**：只要用户没有点名，一律按本技能上文"科研资讯写作"的风格与排版执行，上文所有约束不变。只有用户说"用通用模式""深度长文""定义体""课程转合集"等时才切到对应小节。规则：

- 特意切到模式时，若该模式会产出公众号正文，**排版仍优先遵循本技能的"正文 HTML 排版规范"**（若用户未另行指定排版方式）。凡本技能上文已给出硬约束处，以其为准。
- 合并后这几个来源技能不再单列同名文件，统一在本文件内维护。

## A. 通用自媒体写作（原 公众号写作·通用模式）

适用：情感/职场/观点/干货等非科研公众号。默认排版为 Markdown，若需公众号贴板再转符合上文 HTML 规范。

- **标题**：1 个主标题 + 1–2 个备选；优先反直觉 / 设问 / 数字冲击。
- **结构**：开头抓读者（口语化问候 / 热点 / 数据冲击 / 痛点设问）→ 分节推进 → 结尾给可执行落点。
- **语言**：口语化、短句、去 AI 味；不用「值得注意的是」「综上所述」等空洞过渡句。
- **去 AI 味自查**：删空洞句；把整齐对仗改成有节奏的自然句；避免过度一词一句；保留专有细节。
- **自检**：每段是否有实际信息？标题是否让人想点？结尾是否有抓手？

## B. 深度长文（原 公众号写作·深度长文模式）

- **选题判断 HKR**：一句话选题满足三项越多越好 → `Happy`（快乐/情绪）、`Knowledge`（知识增量）、`Resonance`（共鸣）。三者皆有是长文爆款前提。
- **5 种写型**：按内容调性选用（叙事型 / 论证型 / 清单型 / 访谈型 / 观点社论型），全程保持一致。
- **风格内核**：建立并贯穿全文的独特视角与语气，让文章有"作者的存在"。
- **四层自检体系**：① 信息层（有无实证/唯一洞察）② 结构层（逻辑单向推进）③ 语言层（阅读节奏、可诵感）④ 情感层（情绪起伏）。
- **学习历史风格**：如用户提供历史文章，先抽取其用词、句式、段长、口头禅，再落笔模仿。

## C. 学术干货「定义体」（原 公众号写作·定义体模式）

适用于偏学术/知识型长文。原则：

1. **定义体先行**：核心概念先给 `核心定义：… 核心逻辑：…`。
2. **箭头驱动叙事**：多用 `→`（而非"导致/引起"）串联因果链，如 `CpG 甲基化 → 基因沉默`。
3. **表格对比优先**：两种以上机制/方案对比时用表格，含「对比维度」列。
4. **符号合理使用**：`✅`=文献直接支撑；`⚠️`=合理延伸但原文未明示。（注意：除本模式外，本技能原则上少用 emoji，若用户同时要求科研资讯风格则不适用）
5. **极短段落**：一个观点 = 一段（≤3 句）。
6. **允许未解**：至少 2–3 个「前沿未解问题」。
7. **参考文献收束**：不以"总结/展望"结尾，改以一条核心文献正式引用收束。

结构配方：

```
[标题]（反直觉/设问，≤20字）
[引语]（1–2 句，斜体，制造认知张力）
一、[核心定义] → [核心逻辑]
二、[分层机制拆解]（2–4 个子机制）
三、[对比表格]（≥1 个，维度≥3列）
四、[生物学/临床意义]
五、[前沿未解问题]（2–4 条）
[参考文献]（1 条正式引用，含 DOI）
```

## D. 课程 / 讲义 → 公众号合集（原 course-to-mp-series）
