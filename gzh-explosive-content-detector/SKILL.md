# gzh-explosive-content-detector

**功能**：检测同题材公众号内容有没有出过 10 万+
**类别**：内容四层

## 使用流程

1. 确认任务目标与输入材料（文件路径 / 链接 / 文本 / 截图）。
2. 按「内容四层」领域的最佳实践分步执行：先规划，再执行，最后自检。
3. 产出物保存到用户指定的目录；未指定时询问或使用当前工作区。
4. 涉及多轮产出的任务，先给出大纲/方案供确认，再产出成品。

## 依赖与限制

- 本技能为**指令型技能**（无脚本实现），由 Agent 按上述功能描述直接执行。
- 若功能涉及外部平台（如腾讯/飞书/钉钉/Slack/Notion/Obsidian 等）或外部 API（生图、语音、数据接口等），需用户提供相应的凭证、本地客户端或 API 工具；Agent 按平台官方文档调用，未具备条件时如实说明并给出替代方案。
- 输出内容遵守用户的工作区规则（如删除文件必须移至回收站）。
