# 公众号写作（GZH Writer 合并版）

将以上四个公众号写作技能的完整方法合并于此。默认走「通用模式」，用户指定风格时切换到对应模式；定义体与科研资讯两种风格为**完整继承**，不要丢失其细节。

---

## 使用起点

1. 确认任务：新建推文 还是 改写/润色/洗稿？指定哪种风格（通用 / 深度长文 / 定义体 / 科研资讯）？未指定 → 通用模式。
2. 明确输入材料：文件路径 / 链接 / 文本 / 截图 / 主题。
3. 涉及多轮产出：先给大纲或方案，共识后再出成品。
4. 产出保存到用户指定目录；未指定用当前工作区。
5. 涉及外部平台或 API（公众号后台、生图、数据接口等）：需用户提供凭证/客户端，按其官方文档调用；不具备条件时如实说明并给出替代方案。
6. 删除任何文件必须移至回收站，不永久删除。

## 模式一 · 通用自媒体写作（默认）

- **标题**：给出 1 个主标题 + 1–2 个备选；优先反直觉 / 设问 / 数字冲击。
- **结构**：开头抓读者（口语化问候 / 热点 / 数据冲击 / 痛点设问）→ 分节推进 → 结尾给出可执行落点。
- **语言**：口语化、短句、去 AI 味；避免「值得注意的是」「综上所述」等空洞过渡句。
- **去 AI 味自查**：删空洞句；把整齐对仗改成有节奏的自然句；避免过度一词一句；保留专有细节。
- **自检**：每段是否有实际信息？标题是否让人想点？结尾是否有抓手？

---

## 模式二 · 深度长文（原 kazzk-writing + gzh-writer）

- **选题判断 HKR**：一句话选题同时满足三项越多越好 → `Happy`（快乐/情绪）、`Knowledge`（知识增量）、`Resonance`（共鸣）。三者皆有是长文爆款前提。
- **5 种写型**：按内容调性选用（叙事型 / 论证型 / 清单型 / 访谈型 / 观点社论型），全程保持一致。
- **风格内核**：建立并贯穿全文的独特视角与语气，让文章有"作者的存在"。
- **四层自检体系**：① 信息层（有无实证/唯一洞察）② 结构层（逻辑是否单向推进）③ 语言层（阅读节奏、可诵感）④ 情感层（是否制造情绪起伏）。
- **学习历史风格**：如用户提供历史文章，先抽取其用词、句式、段长、口头禅，再落笔模仿。

## 模式三 · 学术干货「定义体」（原 biogou，完整继承）

以「定义先行、箭头叙事、表格对比、符号验证」为核心的公众号写作风格，适用于偏学术/知识型长文。

### 写作原则

1. **定义体先行**：每个核心概念先给**一句话定义**，再给**核心逻辑**。格式：`核心定义：… 核心逻辑：…`
2. **箭头驱动叙事**：大量使用 `→`（而非"导致""引起"）串联因果链。例：`CpG 甲基化 → 基因沉默`
3. **表格对比优先**：涉及两种以上机制/路径/方案对比时，优先用表格，含「对比维度」列。
4. **符号标记验证**：`✅`=文献直接支撑；`⚠️`=合理延伸但原文未明示。
5. **极短段落**：一个观点 = 一个段落（≤ 3 句）。
6. **允许未解**：每主题至少 2–3 个「前沿未解问题」。
7. **参考文献收束**：不以"总结/展望"结尾，改以一条核心文献的正式引用收束。

### 结构配方

```
[标题]（反直觉/设问，≤20字）

[引语]（1–2 句，斜体，制造认知张力）

一、[核心定义] → [核心逻辑]
二、[分层机制拆解]（2–4 个子机制，各含定义+箭头因果+临床关联）
三、[对比表格]（≥1 个，维度≥3列）
四、[生物学/临床意义]
五、[前沿未解问题]（2–4 条）

[参考文献]（1 条正式引用，含 DOI）
```

### 语言规范

| 类别 | 要求 |
|------|------|
| 段落长度 | ≤3 句，多数 1–2 句 |
| 过渡句 | 删除，"值得注意的是/众所周知"一律不用 |
| 强调 | 仅核心术语加粗，每段 ≤1 处 |
| 因果 | 优先 `→` |
| 结尾 | 不用"总结/展望"，用参考文献收束 |
| 语气 | 平等、清晰，像高年资研究者讲文献 |
| Emoji | 仅 ✅ ⚠️ |

### 工作流

- **新建**：明确主题与知识域 → 检索核心文献（含 DOI）→ 按结构配方生成 → 自查每段是否有实信息、有无空洞句。
- **改写**：提取核心信息 → 忽略原文结构重新组织 → 长段拆 1–2 句 → 文字对比转表格 → 补 ✅⚠️ → 删过渡句/空洞句/AI 高频词。
- **排错**：段落太长→拆 ≤3 句；缺表格→补对比表；像教科书→加 ✅⚠️ 与前沿未解；结尾空洞→换正式引用。

## 模式四 · 科研资讯（原 WeChat Science Writer，完整继承）

模仿头部生物医学科研自媒体人格，将顶刊论文转化为有传播力的公众号资讯文章。读者：临床医生、生信初学者、资源有限的科研团队。

### 标题规则

1. **期刊背书**：`期刊名｜核心发现【＋副标题】`或「热点＋期刊名」。示例：`Cancer Cell ｜ TLS 并非越多越好，生态位才是应答关键！`
2. **数字/规模冲击**：强调"最大规模""29 个器官""256 例样本"。
3. **关键信息前置**：期刊名＋核心发现在标题前半即出现。
4. **可选反常识句式**：「并非越多越好」「关键！」，标点适度。

### 开头手法（任选/组合）

口语化问候（「大家好呀」）/ 热点趋势引入 / 数据冲击开头 / 科学问题设问。

### 叙事结构（漏斗式分节）

1. **研究背景/意义**（是什么热点、解决什么问题）
2. **核心思路/方法**（通俗比喻解释机制，术语必须给解释）
3. **主要结果**（突出样本量、队列规模、生存期、效应量）
4. **小结与转化价值**（「小编总结」收束，落临床意义）

### 语言风格

学术密度适度（ADC、CRISPR、H&E 等术语首次出现给中文解释）；数字强化；情绪克制（用"持续攀升""最受关注"，一般不用 emoji）；给临床医生/生信新人可直接复用的抓手。

### 结尾落点

以「小编总结」/「小结」收束 → 提供**热点思路推荐 / 医生选题指南 / 生信复现思路 / 参考文献** → 帮读者把热点转化为自己的研究选题。

### 输出约定

中文、Markdown；交付含主标题+备选标题、正文、文末扩展阅读/参考来源。不虚构数字，结论忠于论文，不确定处以"待核实"占位。
