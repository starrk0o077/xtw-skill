# 公众号排版发布（合并版）

合并四个公众号排版/发布/抓取类技能的能力，统一工作流。

## 能力矩阵

| 场景 | 处理方式 |
|------|----------|
| 排版 | Markdown → 内联样式 HTML，多套主题可选，可自定义主题 |
| 抓取 | 抓取指定公众号文章内容 |
| 写稿+排版+封面 | 从选题自动产出图文 + 排版 + 封面图 |
| 发布 | 发布到公众号后台/草稿箱 |

## 统一工作流

1. **确认任务**：排版已有内容 / 抓取文章 / 自动写稿一条龙 / 发布？
2. **排版**：将 Markdown 正文转换为内联样式 HTML，内置主题渲染，双关卡质量校验（样式完整性 + 移动端适配）。
3. **抓取**：用户提供文章链接或公众号名，抓取正文并整理为 Markdown。
4. **一条龙**：先给大纲 → 写正文 → 排版 → 生成封面 → 交付预览。
5. **发布**：走官方发布通道（wenyan-cli / 公众号后台粘贴）；涉及第三方登录需用户配合授权。
6. **自检**：样式是否兼容公众号后台粘贴？图片是否已上传？移动端显示是否正常？

## 依赖与限制

- 抓取/发布涉及外部平台（公众号后台、第三方工具），需用户提供凭证或客户端；未具备条件时如实说明并给替代方案。
- 删除任何文件必须移至回收站，不永久删除。
